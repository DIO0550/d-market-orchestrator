# /tmux-team コマンド

永続的なAI CLIチームを tmux セッションに編成し、ボス（オーケストレーター）が動的にタスクを割り振る。

## 使用方法

```
/tmux-team "タスクの説明"
/tmux-team "タスクの説明" --members 4
```

## オプション

| オプション | 説明 | デフォルト |
|-----------|------|----------|
| --members N | チームメンバー数（ペイン数、1〜8） | オーケストレーターが判断（通常3） |

## 実行フロー

### チーム編成（自動）

1. `.orchestrator/` 内の `????-*` パターンをスキャンし最大連番を取得
2. セッションフォルダを作成: `.orchestrator/{連番+1}-{feature名}/`
3. チーム専用スクリプトが未配置の場合、自動配置
4. `init-team-session.sh` でディレクトリ構造を初期化
5. `.orchestrator/team-config.json` が存在すればチーム名・メンバー名を読み込み
6. `tmux-session-create.sh` でtmuxセッションを作成
7. メンバー数を決定:
   - `--members` 指定あり → その数を使用
   - 指定なし → タスクの複雑さから判断（デフォルト3）
8. `tmux-pane-presplit.sh` で N ペインを事前分割し CLI を起動
9. 全メンバーの Ready 状態を待機（readiness probe）

### タスク委任（自動）

オーケストレーターが自身の判断で:

- ユーザーのタスクを分析・分解
- idle メンバーにタスクを割り振り（プロンプトファイル生成 → tmux send-keys で指示送信）
- 複数メンバーへの並列割り当て
- 完了メッセージ（[AGENT_COMPLETE]）を受信し次のタスクを割り当て
- 全タスク完了を判断してユーザーに報告

**オーケストレーターの判断に委ねられる事項**:
- タスクの分解方法
- 各メンバーへの役割・タスク割り当て
- タスクの実行順序（逐次 or 並列）
- レビューの要否と方法
- 完了の判断基準

## 既存モデルとの違い

| 項目 | /tmux-orchestrate | /tmux-team |
|------|------------------|-----------|
| ペイン | オンデマンド作成・破棄 | 事前分割・永続 |
| 役割 | 固定（Explorer, Planner, ...） | 動的（タスクごとに指定） |
| ワークフロー | Phase 0〜4 の定型 | 完全自由 |
| CLI モード | ワンショット | インタラクティブ常駐 |
