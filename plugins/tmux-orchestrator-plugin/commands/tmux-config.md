# /tmux-config コマンド

tmux オーケストレーターの設定をカスタマイズする。CLI 割り当てやチーム設定を対話的に作成・編集する。

## 使用方法

```
/tmux-config
```

## 設定項目

1. **CLI 割り当て** (`default-cli-assignments.json`) — エージェントごとに使用する CLI ツールを指定
2. **チーム設定** (`team-config.json`) — チーム名やメンバー表示名のカスタマイズ（任意）
