# /tmux-setup コマンド

tmux オーケストレーション環境の準備状態を確認する。

## 使用方法

```
/tmux-setup
```

## 実行フロー

1. tmux がインストールされていることを確認
2. 必要なスキルが利用可能であることを確認
3. 環境の準備完了を報告

> スクリプトとテンプレートはスキルの `references/` から直接参照されるため、ファイルのコピーは不要です。
