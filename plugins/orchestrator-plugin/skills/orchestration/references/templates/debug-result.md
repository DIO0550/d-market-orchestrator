# デバッグ分析

## 指示

テスト・Lint 失敗の原因を分析し、修正提案を報告する。
**コードの修正は行わない。分析と提案のみ。**
分析はエビデンスベースで行い、推測で原因を断定しない。

## 重要な制約

- **テスト再実行コマンドは結果ファイル（`{SESSION_DIR}/task-{taskId}/test-runner/result-{round}.md`）の「実行コマンド」セクションから取得する**。PM検出で推測しない。
- 原因分析は具体的な証拠に基づくこと

## 分析手順

### 3段階原因分析
1. **直接原因**: 何が失敗しているか（エラーメッセージ、スタックトレース）
2. **根本原因**: なぜ失敗しているか（コードの問題箇所）
3. **影響範囲**: 他に影響を受ける箇所はあるか
