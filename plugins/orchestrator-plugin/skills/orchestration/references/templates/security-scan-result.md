# セキュリティスキャン結果

## 指示

コードのセキュリティ脆弱性と依存関係のセキュリティ問題を検出し、報告する。
**コードの修正は行わない。検出と報告のみ。**
コマンドを推測して実行してはならない。必ずプロジェクト設定を確認してから実行すること。

## 事前確認

1. `CLAUDE.md` を読み、プロジェクト固有のセキュリティ要件を把握する

## 静的解析チェックリスト

### インジェクション
- SQLインジェクション
- コマンドインジェクション
- XSS（クロスサイトスクリプティング）

### 認証・セッション管理
- 認証バイパスの可能性
- セッション管理の問題

### 機密データの露出
- ハードコードされたパスワード・APIキー
- 機密情報のログ出力

### アクセス制御
- 認可チェックの欠落
- パストラバーサル

### 脆弱性パターン検索

```
検索パターン:
  - "eval\\(" - eval使用
  - "innerHTML" - XSSリスク
  - "password.*=.*['\"]" - ハードコードパスワード
  - "api[_-]?key.*=.*['\"]" - ハードコードAPIキー
  - "exec\\(" - コマンドインジェクションリスク
```
