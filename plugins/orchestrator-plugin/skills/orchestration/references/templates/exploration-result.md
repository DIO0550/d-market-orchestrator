# 探索結果

## 指示

タスクに関連するファイル・既存実装パターン・仕様書を探索し、Planner に必要な情報を提供する。
コードの変更は行わない。探索と報告のみ。

## 事前確認

1. `CLAUDE.md` を読み、プロジェクトのルール・制約・除外パターンを把握する
2. `README.md` を読み、技術スタック・プロジェクト概要を把握する

## 探索手順

1. **Wide（広く浅く）**: ディレクトリ構造を把握し、関連しそうな領域を特定する
2. **Deep（狭く深く）**: 特定した領域の具体的なファイル・コードを読み込む
